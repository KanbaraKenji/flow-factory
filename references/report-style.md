# 汇报风格（线条与卡片）——用户 2026-10-29 提供的参考规范

> 用户原话：「附上最近一次我在公司觉得生成的好的流程图风格（注意风格不包含配色），以及我当时让他自己写的 skill。你可以拿来参考，但不是绝对标准。」
> 汇报主题（`data-calm`）按它微调；逐条对照本图有没有对应语义，有的照做、没有的记在 case-law 里不硬套。

目标：不知情的人第一眼就能说出这张图在讲什么、重点在哪。靠结构说话，不靠装饰。
配色不在本规范范围内：颜色、字体沿用使用者的模板 / 品牌 / 配色方案；没有给就问，不要自己发挥。背景默认白；描边、连线、次要文字需要的中性灰由方案的文字色冲淡得到。状态标记用方案里表示该含义的颜色。色板里没有某个含义的颜色（如驳回没有红）时，用中性色，靠线型、标记形状区分（虚线、✗），并回报使用者，不要把别的颜色调深调浅来冒充。

## 1. 核心原则
- 一次一个焦点：强调的对象一眼看得出来，其余保持安静。动画时同一刻只亮一个节点。
- 能不写字就不写字：用位置、形状、编号、线型表达顺序和关系；卡片里只写名词短语。
- 不用：渐变、阴影、发光、立体、emoji、装饰图标、卡片单边色条。编号圆点、状态标记、箭头有含义，不算装饰。

## 2. 卡片
- 形状：圆角矩形，圆角约为卡片高度的 1/7；描边细（约 1～1.5px）。
- 内容：只放「标题 + 一行副标题」；没有有用的副标题就只放标题（垂直居中），不要硬凑。更多的话写进讲稿或下方面板。
- 尺寸：同一行、同一类卡片同宽同高；并行的卡片完全一样大。副标题放不下时先缩写用词，再把这一类卡片一起加宽，不单独加宽某一张。
- 三档层级：全图所有块状图形只有这三种样子。
  - 常规：白底 + 细描边，深色字。这是基准。
  - 退后（次要、「以前」的做法、等待中）：仍是白底或很浅的中性底，描边更淡，字转灰。不用虚线描边——虚线只留给例外路径。
  - 强调（关卡、重点）：用方案颜色的一档——描边和编号圆点用颜色，底色用它冲淡后的浅色，字色同常规。选够深、能压白字的颜色；浅色只能冲淡当底，不当描边。
  - 强调分色：图里有几类可区分的强调对象时按类分色，取方案里的 2～3 个颜色；一类一种颜色，流程图、甘特条、图例里同一类用同一色。只有一类强调对象时才只用一种颜色。常规、退后两档始终是中性色，不参与分色。
- 编号圆点：实心小圆、白字，圆心压在卡片左上角。一张图只用一套编号，只给主流程里的强调卡片编号；业务本身有编号就照业务编；没有业务编号时，并行的同一步共用一个号。
- 状态标记：小圆，圆心压在卡片右上角，与编号圆点对称；在甘特条上压在条的右端上角。通过：空心圆 + ✓；驳回：空心圆 + ✗；最终完成：实心圆 + ✓。✓ ✗ 用路径画，不用字符。通用流程图只在终点标「完成」；讲某一张具体单据时才标通过 / 驳回。
- 面板（图下方的补充区块）：大圆角、很浅的中性底，左上放标题，标题样式同节点标题。

## 3. 连线
- 只走水平、垂直的折线；不用斜线、曲线。
- 细线（约 2px），全图同一粗细、同一中性色；箭头是小号实心三角，只画在进入卡片的地方，汇合到竖线的线段不带箭头。
- 主流程：节点中心在同一条水平线上，从左到右。
- 分叉 / 汇合：竖线放在两列卡片间距的中点，各支上下对称；没有动作的那一路只画线加标签，不为了对称硬加空节点。
- 例外路径（驳回、退回）：虚线 + 标签，不为退回后的修改步骤另画节点；绕到主流程外侧，不与主流程交叉。两张并行卡都会退回：上面那张从卡顶往上绕，下面那张从卡底往下绕；三张及以上：从汇合竖线的下端引出一条共用虚线往下绕。
- 连线标签：2～4 个字，放在线段旁，不压线。只标「读者看不出为什么往下走」的段；顺理成章的段不标。线段放不下标签时所有列间距一起加大。
- 坐标轴不算连线：比连线更细、更淡。
- 图例：线型、底色、标记代表某种含义而图上旁边没有直接写字说明的，才进图例；编号圆点、终点的完成标记不进图例。放在所说明的那张图 / 面板右上角；同一个含义整页只解释一次。

## 4. 版面
- 大量留白；元素对齐网格，间距一致。
- 图整体在画布内居中；上下空白各不超过画布高的 1/8。
- 主流程一行最多 6 个节点；放不下时把同一角色连续的几步合成一个节点，而不是缩小卡片和字号。
  - flow-factory 补充（用户 2026-11-26）：只能合并**同一个角色**的连续几步；不同角色不合并，并行处理同一件货的几方（会签）也不合并。宁可折行。
- 默认当作要插进 PPT 的图：不带页标题，图例放图的右上角。
- 一张图只讲一件事；同一过程的另一个视角放在下方独立面板。
- 功能逐项介绍：「小图 + 文字」卡片网格，卡片同宽同高。
- 成效数字：数字字号克制（不超过节点标题的 1.5 倍），每个数字配一句口径；能用「每个对象一格」的状态图就不用一排大数字方块；「以前 vs 现在」用两条长度可比的横条。

## 5. 字号（画布 1200 宽）
- 标题（粗）20～22px；正文（常规）14～15px；标签（粗）13～14px。这几个下限就是最小字号，放不下时减内容或合节点，不缩字。
- 编号 / 状态圆点直径约 24px；箭头三角约 8px。不用全大写、不用斜体。

## 6. 动效（演示或录 GIF 用）
- 一个小标记只在连线上移动；进入节点即消失，改由节点描边加粗表示「正在这一步」。
- 缓入缓出，每段 0.6～1.2 秒；整轮约 10 秒，结尾停 2 秒再循环。
- 状态标记直接出现，不弹跳；时间线长条随流程同步线性变长。
- 录 GIF 时第一帧用「全部完成」的画面。

## 7. 交付前自查
1. 所有块状图形是否只有三种样子？同类卡片是否同宽同高？有几类强调对象就分几色了吗？
2. 每张卡片是否只有「标题 + 一行」？连线标签是否 ≤ 4 字、只标在需要的段？
3. 连线是否全是水平 / 垂直？分叉汇合是否对称？例外路径是否绕在外侧、不交叉？
4. 编号是否只有一套？编号圆点、状态标记是否分别压在左上、右上角？
5. 有没有渐变、阴影、发光、emoji、单边色条？有没有自己调出来的颜色？
6. 截图检查：文字有没有压在图形或线上、标记有没有盖住内容、有没有裁切？图是否居中、上下有没有大片空白？
7. 图上的数字口径自洽吗？
